# Plant Disease Detection Using Machine Learning

## About the Project
This project focuses on detecting plant diseases using machine learning and image-based analysis. It aims to support farmers by providing useful disease information and helping them make better crop-management decisions.

## Objectives
- Detect plant diseases from leaf images.
- Support detection across multiple crops.
- Study disease risk and severity.
- Provide useful advisory information for farmers.
- Improve detection under different image backgrounds and weather conditions.

## Datasets
- Kaggle Plant Disease Dataset
- Village Plant Dataset

## Technologies
- Python
- Machine Learning
- Image Processing
- Data Analysis

## Key Focus
The project emphasizes practical disease detection and farmer advisory support.

## Purpose
Academic project developed for learning and research in machine learning and agriculture.
